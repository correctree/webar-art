ARARART 0.11.1 — 円・四角の覗き穴／作品世界への共通適用

■ 適用
1 ZIPを展開。
2 GitHub correctree/webar-art の main のトップで Add file → Upload files。
3 中の ar.html、studio.html、studio、tests、scripts をまとめてアップロードします。外側のフォルダー自体は入れません。
4 mainへコミットし、GitHub Actionsの成功を確認。
5 Render ararart-studio → Manual Deploy → Deploy latest commit。Liveを確認。
6 Studioを再読み込みし STUDIO 0.11.1 を確認。
7 窓を設定して保存→公開。iPhoneで PLAYER 0.11.1 を確認。古い表示なら ? があるURLには &v=0111、ないURLには ?v=0111 を追加。
今回は保存・制作側も変更するためRenderの再デプロイが必要です。

■ 添付図のような共通窓にする手順
1 窓を設定する作品／既存のマスク行を選択。
2 右「配置・表示」→「図形・立体マスク」をON。
3 「円（覗き穴）」または「四角（覗き穴）」を選択。
4 表示する範囲を「内側だけ表示」にします。
5 「この窓をシーン全体へ適用」をON。従来の作品ごとのマスク設定のコピーは不要です。
6 窓を、カメラと作品世界の間に配置・回転します。世界全体を窓の奥へ置いてください。作品より後ろや、視点と平行な位置に窓を置くと作品が見えなくなります。
7 マスクのサイズXYで開口の幅・高さを調整。Zサイズは開口判定には使いません。
8 Studioの視点を動かし、窓の外側では作品が消え、内側から奥の世界が見えるか確認。
9 保存・公開しiPhoneでも確認。

■ 表現方式
円・四角を、図形の範囲を奥行き方向へまっすぐ押し出す方式から、カメラ→開口→作品の視線で判定する覗き穴へ変更しました。窓より大きい作品・遠くにある作品も、窓を通して見える部分は表示します。作品の姿勢・アニメーションや距離感は保ち、窓の寸法に作品全体を縮めて押し込む処理ではありません。
カメラと窓の間にある作品部分、窓の外を通る部分は「内側だけ表示」では隠れます。窓は両側から利用できますが、いずれも視点に対して窓より奥の部分が対象です。箱・球・楕円体・円柱は従来の立体内外判定を維持。

■ 共通窓の対象
・マーカーAR：同じシーン・同じマーカーに属する全作品。異なるマーカーの独立座標世界はまとめません。
・空間配置：同じシーンの全作品（複数マーカーの制作データも対象）。
・GLB、WebM、Spriteに共通適用。影を受ける面にも同じ覗き穴を適用します。
・共通窓は1つをUIから選択。別の窓を共通指定すると前の共通指定は解除。
・共通窓が有効な間、対象作品の個別マスクは共通窓に置き換えて描画します。個別設定は削除せず、共通窓をOFF／削除すると戻ります。複数マスクの積集合は今回未対応です。
・左の行は「共通窓」と表示。右にも適用元を表示します。
・窓のアニメーションは共通元のマスクの時間で同期。
・作品を複製／設定をコピーした場合、複製先は個別マスクとなり共通窓を勝手に増やしません。
・窓の外側で作品のタップは反応しません。

■ 実写背景・編集用表示
切り抜く対象はAR作品群とその影です。実写カメラ映像を黒く塗りつぶす処理ではありません。Studioの背景・編集用グリッド・ギズモ・マスク枠は作業用として残ります。窓枠そのものの装飾や、窓を通り抜けて別世界へ入るモードは含みません。

■ 検証
自動テスト114件成功。視点から開口面への交差計算、従来の押し出し範囲の外にある奥の作品が見えること、斜め視点で見える範囲が変わること、手前の作品の除外、共通対象の選択と解除、共通元の座標・アニメーション時間の適用、影受け面への設定接続、保存・既存UI等を確認。
通常素材と透過動画用の簡略シェーダーをEGL/GLES2（Mesa）でコンパイル・リンク・描画し24条件を確認。窓より大きい奥の形状を表示し、視点移動で見え方が変わるチェックを含みます。Three.js全体／iPhoneのカメラARの実機検証ではありません。
JavaScript構文確認成功。依存パッケージ取得がHTTP403となる環境のため、npmの実ビルド・Studioの実ブラウザー操作・iPhone実機描画は未実施です。GitHub Actionsの結果と実機で確認してください。
