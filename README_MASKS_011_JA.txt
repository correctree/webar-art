ARARART 0.11.0 — 図形・立体マスク／マスクのアニメーション／左パネルのレイヤー

■ 適用手順
1 ZIPを展開します。
2 GitHub correctree/webar-art の main のトップで Add file → Upload files。
3 展開した中の ar.html、studio.html、studio、tests、scripts をまとめてドラッグします。外側のフォルダー自体はアップロードしません。
4 mainへコミットし、GitHub Actionsの成功を確認します。
5 Renderの ararart-studio サービスで Manual Deploy → Deploy latest commit。Liveを確認します。
6 ダッシュボードからプロジェクトを開き STUDIO 0.11.0 を確認。
7 マスクを設定し保存→公開。iPhoneの体験ページで PLAYER 0.11.0 を確認します。古い表示なら ? があるURLには &v=0110、ないURLには ?v=0110 を追加します。
今回はStudioと保存データの検証も更新するため、Renderの再デプロイが必要です。

■ マスクの形
作品を選択→右「配置・表示」→「図形・立体マスク」→ON→「マスクの形」を選択。
・箱：XYZが幅・奥行・高さ。従来の箱マスクを継続利用可能。
・球・楕円体：XYZサイズが同じなら球、別値なら楕円体。サイズは直径。
・円柱：Zが軸・高さ、XYが断面の直径。XY別値なら楕円柱。
・円（平面の窓）：XYの円・楕円の範囲を、ローカルZ方向全体へ押し出して切り抜く。Zサイズは無視。
・四角（平面の窓）：XYの四角の範囲を、ローカルZ方向全体へ押し出して切り抜く。Zサイズは無視。
円・四角は厚みゼロの面と作品が交差した部分だけを表示する方式ではありません。窓として奥行き方向全体に適用します。有限の奥行きが必要なら円柱・箱を選択してください。
各形状で内側／外側表示、位置・回転・サイズ、タップの可視部分判定へ反映します。断面は塞ぎません。

■ 左パネルのレイヤー
マスクを登録すると、左の作品一覧で対象作品の直下に「↳ マスク」の行が現れます。
・マスクの行を押す：マスクを選択して移動・回転・サイズのギズモで編集。
・作品の行を押す：作品の編集に戻る。
・マスクのチェック：ON／OFF。
・マスク行の「削除」：作品を残して、そのマスク設定だけ削除。
・右の「マスクのレイヤー名」：任意名を設定。
現在は1作品につき1マスクで、作品に紐づく子レイヤーです。共通マスクを複数作品で参照する独立シーンオブジェクトではありません。「同じマーカーの作品へ設定をコピー」は従来どおり個別コピーです。
複雑な任意GLB立体のマスク読込は今回未対応。これを追加する場合もマスクレイヤーで選択・操作するUIを継続できますが、複雑形状の内外判定方式は追加実装が必要です。

■ マスクのアニメーション
右のマスク設定→「マスクのアニメーション」→「シーン開始でマスクを動かす」をON。
・片道の秒数：0.1〜60秒。
・移動量XYZ：基準位置からの移動量。
・回転角XYZ：基準回転からの角度（度）。
・終了時のサイズ倍率XYZ：例 2,1,1 でXだけ2倍。
・繰り返す／往復する：同時設定可能。往復OFFの繰り返しは各周期で開始姿勢へ戻ります。
移動・回転・サイズは同時に変化します。作品用の連続アクションのように複数ステップを順番に並べるUIではありません。
Studioの「再生／停止」で確認。停止するとマスクは編集時の基準姿勢へ戻ります。
ARではシーンの作品が表示可能になってから開始。空間配置では配置後に開始し、マーカーARでは認識後に開始します。シーン切替・再開始で初期化します。
作品のメディア再生ON/OFFやタップアクションとは独立した時間で進みます。追跡による表示ゲート停止と全体の停止では進行を止めます。

■ 最初の確認例
1 GLBを選び、マスクの形を「球・楕円体」へ変更。XYZサイズを作品より小さくして切り抜きを確認。
2 XYZを別値にして楕円体を確認。
3 円柱・円・四角を順に選び、作品が動いてもマスク基点は独立しているか確認。
4 アニメーションON。片道3秒、移動X=0.25、回転Z=90、サイズ倍率=1,1,1、繰り返しと往復をONにしてStudio再生。
5 作品とマスクのそれぞれが独立して動くか確認。
6 WebM・Spriteでも形状切り抜きと既存透過を確認。
7 保存→ダッシュボード→再度開き、形・名前・アニメーション設定の保持を確認。
8 公開→iPhoneで描画、影、可視部分のタップ、隠れた部分のタップ除外を確認。
9 従来の箱型マスクも確認。

■ 実施した検証と限界
自動テスト111件成功。形状の内外判定、アニメーションの端点・往復・ループ、保存復元、既存UIの構造、3形式の材料への接続、既存シェーダーフックの維持等を確認。変更したJavaScriptの構文確認成功。
通常素材と透過動画用の簡略シェーダーをEGL/GLES2（Mesa、画面なし）でコンパイル・リンクして描画し、球・円柱・円の内側／外側12条件で中心・隅の表示を確認しました。これはThree.js全体やiPhoneカメラARの実機テストではありません。
この環境では依存パッケージ取得がHTTP403となっているためnpmの実ビルド、Studioの実ブラウザー操作、iPhoneでの実機描画は未実施です。GitHub Actionsのビルド結果と実機で確認してください。
任意GLB立体マスク、複数マスクの合成、共有マスクレイヤー、マスクへのタップトリガー、マスク用の多段連続アクションは今回の対象外です。
