ARARART Studio 0.16.4 — バージョン表示・マーカー操作

変更内容
1. ログイン前のダッシュボードの固定表示0.8.8を修正。Studioとstudio/version.jsの共通バージョンを表示します。HTMLの配信時に再検証を要求するCache-Control: no-cacheを指定します。
2. マーカー切替時はプレビューを終了し、選択作品を解除して画像・作品一覧・編集欄を更新します。非同期の古い画面更新が後から上書きしないよう制御し、編集中マーカーを制作データに保存して再読込で復元します。
3. マーカー欄へ「選択中のマーカーを削除」を追加。全シーンの関連作品がある場合は移動先を選択します。削除確認で移動件数を示し、作品の位置・サイズ・アクションを保って移動します。残す画像から.mindを再生成し、targetIndexを振り直します。失敗時は元の登録を保持します。作品のある最後のマーカーの削除は拒否します。作品がない最後のマーカーは空の下書きに戻せます。

適用
1. ZIPを展開します。
2. correctree/webar-art の同じパスへ9ファイルを上書き・追加してmainへコミットします。フォルダー構造を維持してください。
   studio.html / dashboard.html
   studio/editor.js / studio/dashboard.js
   studio/version.js（新規） / studio/marker-management.js（新規）
   publisher/server.mjs
   tests/guided-layout.test.mjs / tests/marker-management.test.mjs（新規）
3. GitHub Actionsの成功を確認します。
4. RenderのARARART StudioサービスでManual Deploy → Deploy latest commit、Liveを待ちます。
5. ダッシュボードとStudioを再読み込み。古い表示ならMacのChromeでCommand + Shift + R。両方が0.16.4であることを確認します。

確認
・ログイン前もダッシュボードに0.16.4が表示される。
・2枚のマーカーを切り替えると中央のマーカー画像と、そのマーカーに所属する作品一覧が切り替わる。空間配置モードでは作品群は従来どおり全表示。切替は作品の所属自体を変更する操作ではありません。
・保存後に同じプロジェクトを開き直して選択マーカーを復元できる。
・マーカー欄で移動先を選択して削除し、全シーンの関連作品が残る。
・マーカーARとして再公開し、残した画像で認識できることを実機で確認する。

バージョン表示・選択の修正だけなら既存作品の再公開は不要です。マーカー削除を公開版へ反映するときは再公開してください。

検証
ローカルnpm test：192件成功、失敗0。変更JavaScriptの構文確認成功。選択復元、プレビュー終了と選択更新、削除後のマーカー順・参照・作品設定、失敗時の保持、共通バージョン、既存UIの構造をテストしました。GitHub APIやUIの検証はスタブ／最小DOMを使用しています。実ブラウザー、実画像でのMindARコンパイル、iPhoneでの追跡、実環境のデプロイは未確認です。
