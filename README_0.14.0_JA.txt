設定:
各ACTION枠の中にトリガー選択欄があります。
- 前のACTION完了後: 前のACTIONの全レイヤー終了後、そのまま開始。
- タップ: 自分の順番で待機し、それ以後に作品をタップすると開始。
- シーン開始: シーン開始を記録。自分の順番が来たら実行。
ACTIONは常に上から順に進み、枠内だけが同時再生です。
後方のシーン開始ACTIONが先行ACTIONへ割り込んで並行起動する仕様ではありません。
先頭のACTIONで「前のACTION完了後」を選ぶと、シーン開始で実行します。
マーカーARでは、シーン開始処理は対象マーカーの認識後に実行されます。
先頭にシーン開始の出現があれば開始前は非表示になります。

例:
ACTION-01 トリガー「シーン開始」→ 出現（フェード1秒）
ACTION-02 トリガー「タップ」→ 移動（Z0.5、2秒）
ACTION-03 トリガー「前のACTION完了後」→ 回転（Z90度、1秒）
表示後に待機。作品タップで移動し、その後に回転します。
待機位置に達する前のタップは将来のACTIONを解除するために予約されません。
再生中のタップは既存の「再タップ」設定に従います。
タップ待機中は「再生中は無視」であってもタップで先へ進めます。
タップOFFの作品はタップ待機から進めないので左リストのON/OFFを確認。
シーンを入り直すとトリガー待機状態も初期化します。

移行:
既存データは先頭ACTIONに従来の作品トリガーを継承。
2番目以降は「前のACTION完了後」を継承。
連続アクションON時、従来の全体トリガー欄は非表示。
通常の反応（連続アクションOFF）のトリガー欄は維持。
再タップ・終了時の設定は作品全体に適用する欄として上部に維持。
別ACTIONへアクションを入れると移動先ACTIONのトリガーに従います。
同時再生解除時は最初のアクションに枠のトリガー、残りは前の完了後を設定。
