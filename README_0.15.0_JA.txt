対象: correctree/webar-art、0.14.1適用済み環境向け。
PNG/JPG、同時レイヤー、ドラッグ、各ACTIONの3トリガー、影、マスク、録画を維持。
追跡アルゴリズムの変更はありません。

新しいアクション:
「素材アニメーションを再生」
- 開始位置: 先頭から / 続きから。
- 繰り返し: 1回 / ループ。
- 次のACTIONへ: 再生開始後すぐ / 再生完了後。
- GLBでは内蔵クリップを選択。全アニメーションも選べます。
  全アニメーションの完了待ちは、選択した全クリップの終了まで待ちます。
- ループは終了しないので再生完了待ちは選べません。
- 1回再生のSpriteは最後のフレームで止まります。

「素材アニメーションを一時停止」
素材の再生だけをその位置で止めます。移動・回転・フェード等は継続。
再開は「素材アニメーションを再生」→「続きから」。
従来の「停止」は指定時間だけ作品の動きと素材を止め、その後に再開する別機能です。

使い方:
1. GLB（内蔵アニメーションあり）/ WebM / Sprite ZIPを選択。
2. 連続アクションを使うをON。
3. 「素材アニメーションを再生」を追加して設定。
4. 同時に動かす場合は、レイヤーの⠿を「出現」「移動」が入ったACTIONへドラッグ。
5. 全レイヤー終了後に次へ進みます。
   素材側を「再生開始後すぐ」にすると、素材の再生自体は続けたまま、他の動きの終了後に次へ進めます。
6. Studioでプレビューし、保存・再公開・iPhoneで確認。

例1:
ACTION-01 シーン開始: 出現（1秒）＋移動（2秒）＋素材再生（先頭/1回/完了待ち）。
ACTION-02 前の完了後: 消える（1秒）。
素材と移動が両方終わると消えます。

例2:
ACTION-01 シーン開始: 素材再生（先頭/ループ/開始後すぐ）。
ACTION-02 タップ: 素材一時停止。
ACTION-03 タップ: 素材再生（続き/ループ/開始後すぐ）。

再生設定の優先:
素材再生レイヤーを持つ作品は、シーン開始時の自動再生よりレイヤーが優先。
既存のトリガー時再生/GLBクリップ/ループ設定も素材レイヤーを優先。
素材一時停止レイヤーだけを持つ作品では、元の自動再生状態を維持して一時停止できます。
同一ACTION内に素材再生を2つ、または再生と一時停止を同居させることはできません。
PNG/JPGと、内蔵アニメーションのないGLBには追加できません。
新しいアニメーションをGLB内に生成する機能ではありません。
WebMの音声トラックは今回もミュート。音は既存の「音」レイヤーを使用。

確認項目:
- GLBクリップ選択、先頭/続き、1回/ループ。
- WebMとSpriteの先頭再生・一時停止・続きから再開。
- 素材再生中に作品が移動する。
- 完了待ちでは素材終了まで次へ進まない。
- 素材だけの一時停止中も作品の回転/移動が動く。
- 保存して開き直した時とiPhone再生で同じ設定が反映される。
動画再生がブラウザーに拒否された場合はエラーを確認し、再生許可を確認してARを開始し直してください。
