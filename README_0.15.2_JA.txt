ARARART Studio 0.15.2 — 右パネルのスクロール修正
0.15.1適用済み環境向け。Studio表示のみの変更です。

修正:
デスクトップでは画面の残りの高さを編集領域へ割り当て、グリッド行の最小サイズを0に指定。
左右パネルを高さの決まった独立スクロール領域へ設定。
右パネル下端へ余白を追加し、最後のACTIONの操作へ到達できる構成。
小さいウィンドウでは右パネルの最大高さを75dvhとして独立スクロール。
AR体験ページのスタイルへ影響しないようStudio専用クラスで指定。

反映:
1. GitHub correctree/webar-art の最上位へstudio.htmlを上書き。
2. studioフォルダー内へstyle.cssを上書き。ZIPのフォルダーごとのアップロードでも可。
3. mainへコミットしGitHub ActionsとRenderの更新完了を待つ。
4. Studioを再読み込みし STUDIO 0.15.2 を確認。
5. 右パネル上へマウスを置いてホイール/トラックパッドで下へスクロール。
6. 最後のACTION、アクション追加欄まで到達できるか確認。
7. アコーディオンを開いても末尾まで移動できるか確認。
   ウィンドウ高さを縮めた場合やブラウザー拡大時も確認。
