# ARARART 0.9.0 — Studio作品群の空間配置

## 既存環境への適用（correctree/webar-art）
1. この差し替えZIPを展開します。既存の制作ZIPではありません。
2. https://github.com/correctree/webar-art の main ブランチ、リポジトリ最上位で Add file → Upload files を開きます。
3. 展開フォルダーの**中身**（studio、scripts、tests、publisherのフォルダーと、ar.html、studio.html、package.json、README_SPACE_090_JA.md）をまとめてドラッグします。外側のARARART-0.9.0-group-spaceフォルダー自体はアップロードしません。publicフォルダー内には置きません。
4. mainへコミット。ActionsのPagesビルド・デプロイが緑になるまで待ちます。
5. Renderの ararart-studio サービスで Manual Deploy → Deploy latest commit を実行し、Liveまで待ちます（自動デプロイOFFの場合も必要）。環境変数や永続ディスクは変更しません。
6. Web Studioを再読み込みし、既存の保存済みプロジェクトを開きます。

## 制作・保存・公開
1. 「保存・公開」内の「プロジェクト」→「体験モード」で「空間配置（マーカー不要）」を選択します。
2. 「配置・反応」へ戻ります。同じシーンの全マーカーに属する作品が同時表示されます。
3. 既存の位置XYZ、回転XYZ、サイズ、透明度、影、反応を編集します。Zが高さです。
4. 複数マーカーに属する作品は、マーカー同士の現実の位置関係ではなく、各マーカーの原点を一致させてまとめます。重なる作品はStudio上で位置を調整してください。
5. 「保存・公開」で「空間配置の全体倍率」を設定します。初期値0.35。作品個別の座標・倍率を書き換えず、全作品へ同じ倍率を適用します。メートル単位の実寸保証はありません。
6. 「プロジェクトを保存」でサーバー保存し、「公開する」で公開します。
7. 公開完了のQRまたはURLをiPhoneのSafariで開きます。URLは従来どおり ar.html?scene=プロジェクトID です。保存された体験モードで自動的に空間ARになります。

## iPhone
1. 「ARを開始」を押してカメラを許可します。
2. 模様のある床や机をゆっくり映します。特徴点の目印が安定したら「作品群をここに置く」を押します（画面タップでも配置可能）。
3. シーン全体が一つの親グループとして配置されます。StudioのX/Y平面がARの水平面へ、Z軸が上下方向へ変換されます。
4. 配置後に作品をタップし、設定済みのアニメーション・音・連続アクションを確認してください。シーン開始トリガーは配置後に開始します。シーンを切り替えても配置基準は保持します。
5. 「置き直す」で作品群を非表示にして、新しい候補へ再配置します。置き直したときは、現在のシーンの反応を初期状態に戻します。
6. 「操作を隠す／表示」で操作パネルを切り替えられます。
7. 問題時は「空間配置の診断を保存」を押してJSONを保存してください。

## 確認ポイント
- GLB、WebM（変換済みSafari用MP4）、Spriteが同じシーンで同時表示される。
- 作品間の間隔・大小・回転・透明度がStudioの配置を反映する。
- 左右に歩いても作品群が配置した場所に留まる。
- タップ対象の限定、音、連続アクション、シーン開始、シーン切替が動く。
- 置き直し・終了・再開始で位置や再生状態が混ざらない。
- マーカーARの既存プロジェクトは引き続きマーカー方式で再生される。

## 現時点の範囲
- 特徴点への配置です。床・机の面の広がりや傾きを検出する機能ではありません。
- 制作側は既存のマーカー登録データを配置基準として残します。体験時に印刷マーカーは不要です。マーカー登録なしの新規制作フローは本版の対象外です。
- 終了後の位置復元、利用者同士で同一実空間位置を共有する機能、現実物体による遮蔽は未対応です。
- 体験モードはプロジェクト単位です。従来のマーカーARも残ります。表示確認だけなら公開URLに &mode=marker または &mode=space を追加して一時的に切り替えられます。
- 初回のビルド時に既存依存パッケージ（8th Wallのバイナリエンジン等）が必要です。ライセンスは既存の同梱通知を参照してください。

## 実装と検証
- 共通親グループの移動、Z-upからY-upへの固定回転、共通倍率だけで配置します。作品のposition/rotation/scaleや連続アクションのデータは書き換えません。
- 検証05と同じ前方・近距離除外、650ms安定確認、250ms候補期限を使います。
- 自動テスト96件成功。構文確認済み。iPhoneの統合版の実機検証は未実施です。
