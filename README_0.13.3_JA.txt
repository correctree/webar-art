ARARART 0.13.3 レイヤードラッグ修正版（0.13.2適用済み環境向け）

修正:
マウス移動/解放をPointer Eventsで直接処理。
ドラッグ開始は各レイヤーの⠿。ACTIONの枠内全体へドロップ可能。
別ACTION内のアクション見出しも、移動先ACTIONへの追加として処理。
同じ枠内の挿入位置と枠間の挿入位置は従来どおり。
競合するアクションは理由を表示して移動を拒否します。
