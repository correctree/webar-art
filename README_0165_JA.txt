ARARART Studio 0.16.5 — 同一シーンでマーカーごとに別の作品を制作

0.16.4適用済み環境向けです。

修正
・空間配置モードのとき、Studioでマーカーを切り替えても全マーカーの作品を表示していた条件を修正。制作画面は体験モードと独立して、選択中マーカーの作品だけを一覧・中央画面に表示します。
・「作品」の下に追加先マーカー名と作品数を表示。
・作品追加時に、プレビュー終了処理が選択マーカーを変更しても、追加する作品のマーカー所属と現在シーンを維持します。
・同じファイルを別マーカーへ続けて追加できるよう、ファイル選択欄をリセットします。
・他のマーカーの作品データは保持します。公開プレイヤーの処理は変更しません。

適用
1. ZIPを展開し、5ファイルをcorrectree/webar-artの同じパスに上書き・追加してmainへコミット。
2. GitHub Actions成功を確認。
3. RenderでManual Deploy → Deploy latest commit、Liveを待つ。
4. Studioを再読み込み。STUDIO 0.16.5を確認。古い表示はCommand + Shift + R。

確認操作
1. 同じシーンを選択したままにします。
2. 「編集中のマーカー」でAを選ぶ。「作品」の追加先がAであることを確認して作品Aを追加。
3. 「編集中のマーカー」でBを選ぶ。作品Aが制作画面の表示から外れ、Bの作品だけの一覧へ切り替わります。
4. 追加先Bを確認して別の作品Bを追加。
5. Aへ戻すと作品A、Bへ切り替えると作品Bを編集できます。シーンを追加し直す必要はありません。
6. 保存してプロジェクトを開き直し、同じ割当が保たれていることを確認。

公開について
マーカー画像ごとに別のARを認識・再生させる場合は、ヘッダーから保存・公開を開き、「体験モード」を「マーカーAR」にして公開してください。
「空間配置」は体験時に同じシーンの作品を一括配置するモードです。この設定は今回、自動では切り替えません。
制作画面の表示は選択中マーカーに限定されますが、他のマーカーの作品は削除されません。
作品追加・編集や体験モードの変更をAR体験へ反映するには保存後に再公開が必要です。
