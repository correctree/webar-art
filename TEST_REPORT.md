# ARARART 0.8.0 verification

92 automated tests passed with zero failures. JavaScript syntax checks passed. Existing tracking, dashboard, folders, installer, shadows, media conversion, audio, tap, saving and publication regression tests pass.

New tests cover rising-edge sound detection, quiet rearm and cooldown, near distance hysteresis and dwell, tracking eligibility, self-audio suppression, independent object states, hide/show/camera steps, keep/reset initial visibility, automatic triggers while tap is OFF, schema bounds and project JSON export/restore, RMS input, microphone tracks/context cleanup, permission denial and stop during permission waits. Shared geometry adapter tests normalize distances by marker width, allow hidden objects to reappear, and check camera-facing orientation under authored rotation and unequal XYZ scale using math/Three adapter mocks. DOM contract checks the new trigger controls. A pre-existing scene-deletion scope error was fixed while updating scene action cleanup.

Production build: npm run build is blocked by absent dependencies. npm install --ignore-scripts and a separate Three package fetch both return registry HTTP 403 in this environment. No real browser/GPU or iPhone hardware tests were performed. APPLY.sh installs dependencies and requires tests, production build and dist checks on the user's Mac before git push. Tests involving Three adapters use mocks and do not substitute for visual/device acceptance.

Known limits: microphone detects volume, not spoken commands. Sound playback suppresses mic triggers during output and 0.6 seconds afterwards. Proximity is estimated in marker-width units, not calibrated centimetres; only recognized markers are eligible. Each object shares one action chain for its enabled triggers. Camera-facing uses local +Z and overrides action rotation while enabled. Hidden media keeps its timeline; hidden objects cannot be tapped. New space placement is not included. No new Render deployment or live GitHub publication was performed here.
