ARARART Studio / Player 0.13.0 — JPG作品・出現＋移動

適用先: correctree/webar-art（gif-webmではありません）
録画0.12.2、マスク0.11.1の既存ソースを維持した更新です。
今回マーカー追跡アルゴリズムは変更していません。

1. 既存プロジェクトを保存し、念のため制作ZIPも取得。
2. ZIP内の studio フォルダー、studio.html、ar.html、tests フォルダーを
   GitHub correctree/webar-art の最上位へアップロードし、mainへコミット。
   フォルダー構成を維持し、public内に入れないでください。
3. GitHub Actionsが完了するまで待ちます。
4. Render ararart-studio のデプロイも完了させます。
   自動デプロイOFFなら Manual Deploy > Deploy latest commit。
   サーバー側も schema/action-sequence を検証するためRender更新が必要です。
5. Studioを再読み込みし STUDIO 0.13.0 を確認します。

JPG:
作品追加から .jpg / .jpeg を選択。平面画像として縦横比を維持。
長辺4096pxを超える画像は4096pxへ縮小しJPEG品質95%で再保存。
既存上限24MBは維持。両面表示・配置・XYZ・透明度・影・マスク・反応に共通対応。
背景透過を新たに作る機能ではありません。

出現＋移動:
作品選択 > 連続アクションを使う > 追加するアクション
「出現＋移動（同時）」を追加します。
例: 移動量X=0,Y=0,Z=0.5、所要時間2秒、待ち時間0秒、フェード時間2秒。
シーン開始で使う場合は先頭に配置。開始前は非表示になります。
タップでも使用可。開始時に透明になり、移動とフェードを同時に開始。
待ち時間は出現だけに作用し、その間も移動します。
移動・出現の長い方が終わってから次へ進みます。
往復・繰り返しは移動のみ。出現は一回です。
従来の「出現」「移動」は従来どおり順番に再生されます。

プレビューで出現中に移動することを確認。
