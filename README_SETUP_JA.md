# WebAR Art 0.5.3 — 影の方向・受け面の拡張

## Macへの適用
1. 必要な編集データを制作ZIPまたはサーバーへ保存。
2. 現在のStudioのターミナルでControl+C。
3. ZIPをDownloadsに保存し、次の2行を実行。

```bash
unzip -o "$HOME/Downloads/WebAR-Art-0.5.3-shadow-layout.zip" -d "$HOME/Downloads"
bash "$HOME/Downloads/WebAR-Art-0.5.3/APPLY.sh"
```

旧コードをバックアップし、依存導入・58件のテスト・実ビルド・配信ファイル確認が通った後にGitHubへpushし、localhostサーバーを起動します。
独自素材、マーカー、.env、.git、.studio-data は保持します。失敗した場合はその場で停止します。

Studio: http://localhost:8080/studio.html を再読み込みしてSTUDIO 0.5.3を確認。
GitHub Actionsで今回のプログラム更新が成功してから、作品の公開へ進んでください。
RenderのStudioを使う場合はManual Deployも必要です。GitHub App設定は docs/GITHUB_CONNECTION_JA.md。

## 3つの作業画面
### 1. マーカー・シーン
マーカー登録・選択・印刷、シーンの追加・選択・名前・開始シーン・削除を同じ画面で操作します。
マーカーは認識画像と配置の基準、シーンは作品をまとめた場面です。統合は編集画面の統合で、複数マーカーと複数シーンの既存データ構造は維持します。

### 2. 配置・反応
GLB / WebM / Sprite ZIPを追加。左の作品一覧から選び、右側で位置・サイズ・回転・不透明度・影・タップ・音・場面転換を設定。
サイズのチェーンONはXYZの比率を維持、OFFは個別変更。左のタップON/OFFは反応設定を保持します。
「作品の影を表示」を作品ごとにON。GLBは形状、Spriteは表示フレームのアルファ、透過動画はSafari用packed-alphaのマスクを影に反映します。透過のない動画は長方形の影です。
影の濃さ・方向・範囲はプロジェクト共通。「奥（マーカー上側）」が初期値です。「影を受ける範囲」は初期値4倍、1〜8倍に変更できます。縦横を同じ倍率で広げるため紙の縁を越えて影を表示します。範囲外では影は切れるため必要に応じて倍率を上げてください。実際の机の輪郭・段差は認識せず、マーカーと同じ平面に透明な受け面を置きます。
「シーン切替 ON」で切替先とタップからの待ち時間を設定。先に1画面目で切替先を作り、各シーンに作品を配置してください。
右の再生／停止でプレビューし、中央の作品をクリックすると反応と切替を確認できます。

### 3. 保存・公開
ブラウザー自動保存・制作ZIP・サーバー保存・公開を同じ画面で操作します。
保存は編集データの保管で、公開中の体験を更新しません。「公開する」で公開版を更新し、配信確認完了後QRとURLを表示。
新規確認は既存と異なる体験ID。以前と同じ体験を更新する場合は同じID。
localhostは既存MacのGit認証、公開サーバーはGitHub App認証を使用。
サーバーの保存を開くには体験IDを入力。同じサーバーと同じ認証ユーザーで開きます。
localhost保存先はリポジトリの .studio-data、GitHubへ含めません。RenderはPersistent Disk /var/data と DRAFT_DIR=/var/data/webar-drafts が必要です。未設定のサーバーディスクは再デプロイ等で消える場合があります。

## iPhoneの影を確認する順序
1. GitHub Actionsで今回のプログラム更新完了を確認。
2. 配置・反応でGLB・WebM・Spriteそれぞれの影をON。
3. 保存・公開で同じ体験IDへ再公開し、QRを表示。
4. iPhoneで公開ページを再読み込み。PLAYER 0.5.3を確認。
5. ARを開始してマーカーを認識。3形式の影がマーカー面に出るか確認。
6. マーカーを傾けても影が追従し、見失うと作品と影が非表示になるか確認。
7. Spriteのフレーム・動画の輪郭に合わせて影が動くか確認。透過部分が長方形の影にならないか確認。
8. 宝石だけのタップ反応・音・シーン切替が維持されるか確認。

## ARの影の修正内容
0.5.1では影用のライトとカメラ範囲が編集画面の座標に固定されていました。
0.5.3はライトとその注視点を各マーカーの子要素へ配置し、マーカーのワールド拡大率に応じて影の計算範囲とバイアスを毎フレーム更新します。
動画・Spriteは専用の深度描画を使用。透過動画の右半分のアルファマスクを参照し、Spriteのフレーム切替と同じテクスチャを使います。

## 検証範囲・上限
55件の自動テスト成功。ブラウザー/WebGL描画、実Viteビルド、iPhoneの影と処理速度は本環境では未確認。詳細はTEST_REPORT.md。
マーカー8、同時追跡2、シーン12、全体48作品、素材48MBの既存上限を維持。
まずマーカー1枚・軽い3作品で影を確認してください。
旧0.5.0/0.5.1の制作ZIPを利用できます。影は既存設定を引き継ぎ、未指定の作品はOFFです。
公開QRの配信確認修正を同梱。音声入力・顔・手の追跡、20枚切替最適化はこの版の対象外。
