左 シーンレイヤー:
従来のシーン選択プルダウンを、各シーンの名前を表示するレイヤー一覧へ置換。
行をクリックして編集シーンを選択。開始シーン・作品数を表示。
⠿をドラッグして上下へ並べ替え。ドロップ行の上半分/下半分で前/後へ挿入。
順序だけを変え、シーンID・開始シーンID・各切替先は保持。
並べ替えがシーンの自動連続再生を設定するわけではありません。
名前変更・追加・削除・開始シーン指定は既存の操作を使用。

左 作品レイヤー:
作品ごとに「表示中／非表示」ボタンを追加。
非表示は編集作業だけでなく、保存・公開したARにも反映します。
非表示作品は再生/タップ/自動トリガー対象から外し、影も表示しません。
再び表示中に戻せば作品データとACTION設定はそのまま復帰。
非表示作品の数値編集は可能。ドラッグ用ギズモは非表示中に出しません。
表示切替は編集モードで行います。プレビュー中の切替は無効です。
ACTIONの「消える／出現」は再生中の演出で、作品レイヤーの非表示とは別。
作品レイヤーを非表示にしたものは出現アクションでも表示されません。
マスクの設定データは維持されます。共通窓の無効化はマスク行のON/OFFを使ってください。

右 アクション:
「反応・アニメーション」という上位カテゴリーを「詳細設定（従来の反応）」へ変更。
メインの「アクション」を上側へ移動し、標準で開く構成。
従来の反応設定はデータ互換のため削除せず、下側の折りたたみへ整理。
音素材の追加はアクション内で行えるよう移動。

ヘッダー:
「空間配置」「既存AR」の旧ページへのリンクを削除。
マーカー/空間配置の体験モード選択は保存・公開パネルの設定を使います。
ダッシュボードへ戻る既存の導線は維持。
