# ARARART STUDIO 0.17.0 — フェイストラッキング統合版

## 基準と状態
ユーザー提供 webar-art-main(3).zip（Studio 0.16.6）と、実機確認済みFACE LAB 0.1.3を基準。
Studio編集・保存・公開と既存プレイヤーへの統合を実装。統合後のiPhone実機確認は未実施。

## 適用
このZIPは追加・差し替えファイルのみ。既存リポジトリを削除しないでください。
1. ZIPを展開。トップレベルの各フォルダーとファイルを、GitHub correctree/webar-art 最上位の Add file → Upload files へドラッグ。
2. 同じパスへ上書きしてmainへコミット。ZIPの親フォルダー自体をアップロードしないこと。
3. GitHub Actionsの成功を確認。失敗した場合はRenderへ進まずエラーログを共有。
4. Render → Manual Deploy → Deploy latest commit。
5. ダッシュボード・Studioを再読込し0.17.0を確認。
6. 新規プロジェクトを作成して下の検証を実施。
公開ページのコードも更新されます。既存のマーカー作品を顔モードへ変更した場合は、保存・再公開が必要。

## 最初の制作手順
1. ダッシュボードで新規プロジェクトを開く。
2. 左パネル上部「体験モード」→「フェイストラッキング」。マーカー画像の登録は不要。
3. 「編集中の顔の配置先」→「鼻」を選ぶ。
4. GLBを追加。位置XYZ・回転・サイズを既存の右パネルで調整。
5. 「頭上」へ切り替えて別作品を追加。鼻／頭それぞれの作品を編集できます。
6. 「視点を戻す」で正面へ。編集画面は選択中配置先を原点とする概略表示です。実際の顔映像・顔形状のプレビューではありません。
7. 保存 → ページ再読込 → 鼻／頭と作品・数値が復元されることを確認。
8. 公開 → 完了後のQRまたはiPhone用リンクをSafariで開く。
9. 「ARを開始」を押すと前面カメラで顔を検出。マーカー不要で両配置先の作品を同時に表示。

## 配置の意味
1単位は検出された顔の幅を基準にした相対値。実寸ではありません。
Xは左右、Yは上下、Zは手前。公開映像・作品はFACE LAB同様に左右反転するため、画面上のX方向も反転します。
頭上は額と顎からのオフセットで推定。深い横向きでの精度は実測が必要です。
鼻・頭はそれぞれ顔の姿勢に追従します。推論上限15回/秒。

## 保存と既存作品
experienceMode:'face'、作品ごとのfaceAnchor:'nose'/'head'を保存。
マーカー付きの既存プロジェクトを顔へ切り替えた場合、元のmarkerId・画像・認識データを保持し、顔の初期配置先を鼻に設定。
顔モードで新規追加した作品にはmarkerIdがないため、その作品があるままマーカー/空間モードへ戻す操作は拒否し、説明を表示します。既存作品の所属先を勝手に変更しません。
顔専用プロジェクトとマーカー/空間プロジェクトは別々に作成する運用を推奨。
公開URLは従来通り ar.html?scene=...。プレイヤーがJSONのモードを読んで顔処理を起動します。
保存用JSONを改変せず、再生時だけ鼻/頭を内部アンカーとして構成。

## 表現・操作
既存MediaSceneとBehaviorを使い、GLB/画像/Sprite/動画、タップ、ACTION、音、シーン切替を接続しています。
GLB以外の素材や複雑なACTIONを組み合わせたiPhoneでの動作は未検証。
顔の背景遮蔽、表情トリガー、複数人追跡は未実装。
顔モードの録画ボタンと影の設定は無効。顔の実物への影投影はありません。
顔を見失った際の再生継続/一時停止は既存の設定を利用。表示は顔の再検出まで隠れます。
端末内で顔解析し、映像・特徴点を保存/送信しません。外部CDNからMediaPipeとモデルを取得します。

## iPhone確認項目
- QRから顔モードが開く。マーカーは要求されない。
- 鼻と頭のGLBが同時に追従。
- 顔が画面外に出ると非表示、戻ると再検出。
- 停止/再開3回、縦横回転で映像と作品がずれない。
- 作品のタップが左右反転した表示位置で正しく当たる。
- ACTIONとシーン切替。2シーン目でもアンカーが維持される。
- 既存マーカーARと空間配置の起動・作品表示。
