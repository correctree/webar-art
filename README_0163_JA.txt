ARARART Studio 0.16.3 — 制作パネル整理

変更内容
・左パネルの「制作」「保存・公開」切替ボタンを削除。
・マーカー／シーン／作品の制作パネルを常時表示。
・下部バーを「再生」「停止」「視点を戻す」の順に配置。保存・公開中も利用可能。
・保存／公開は既存のヘッダーから開きます。「公開へ」は開いた後「制作へ戻る」へ切り替わります。

適用方法
1. ZIPを展開。
2. correctree/webar-art の同じ場所へ以下を上書きしてmainへコミット。
   studio.html
   studio/editor.js
   studio/style.css
   tests/guided-layout.test.mjs
   ※フォルダー構造を維持してください。更新テストも必要です。
3. GitHub Actionsの成功を確認。
4. RenderのARARART Studioサービスで Manual Deploy → Deploy latest commit を実行しLiveを待つ。
5. Studioを再読み込みし「STUDIO 0.16.3」を確認。古い表示ならMacのChromeでCommand + Shift + R。

確認ポイント
・左の切替ボタンがなく、マーカー／シーン／作品が表示される。
・ヘッダーで保存・公開へ移っても、左の制作パネルは表示されたまま。
・ヘッダーの「制作へ戻る」で右側を編集用の表示に戻せる。
・下部の「停止」の右隣に「視点を戻す」がある。
・視点を動かしてから「視点を戻す」を押し、初期視点へ戻る。

今回の変更はStudio UIとその既存テストです。既存作品の再公開は不要です。
